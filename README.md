This repository documents my ongoing learning in programming, computer science, and cybersecurity.

I use it to keep structured notes, explain concepts in my own words, and publish small projects that demonstrate what I have practised.

## Featured project

### [Number Processor](C/01-control-flow/number-processor/)

A small C command-line program that reads an integer, skips odd numbers, sums even numbers, and uses `continue` and `break` to control a loop.

The project includes its source code, build instructions, example output, test cases, and a learning write-up.

## How I document my work

For each project, I aim to include:

- The problem or goal
- Concepts practised
- How the program works
- Build and run instructions
- Example input and output
- Test cases
- Limitations and possible improvements
- What I learned

This is an active learning repository. Projects and notes will be improved as I develop my skills.
