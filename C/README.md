# C Programming Learning Journey

This section documents my progress while learning the C programming language through notes, exercises, debugging, and small projects.

## Topics covered

- Variables and data types
- Standard input and output (`printf`, `scanf`)
- Arithmetic and comparison operators
- Logical operators (`&&`, `||`, and `!`)
- Conditional statements (`if`, `else if`, `else`)
- Conditional (ternary) operator (`?:`)
- Loops (`while`, `do-while`, and `for`)
- Nested loops
- Loop control statements (`break` and `continue`)
- Function prototypes, parameters, and return values (introductory practice)

## Learning approach

I write the code myself, test it, investigate compiler errors, and document what I learn. The examples and projects in this directory are part of an ongoing learning process, so they may be improved as my understanding grows.
